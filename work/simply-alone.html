Work / Hoodie capsule

Simply Alone Studios

A hoodie capsule carrying a quiet wordmark and a back print that says more than the front.

Year
2024
Services
Apparel graphics, Lettering
Deliverables
Hoodie graphics, front and back

The front is held deliberately small: a stacked wordmark with a rule under it, sized so it reads as a label rather than a slogan.

The back takes the room. A wide lockup with the studio name and a script tail, set to sit across the shoulders, so the piece works from behind at a distance.

A second graphic runs looser - layered type and a drawn ellipse over a washed brown body, printed soft so it reads as something already worn in.

“The front reads as a label. The back takes the room.”
